# Third-Party Notices

Thank you to the authors below, whose work this project draws on, and above all to Paul Bakaus for Impeccable and Matt Pocock for his skills, which shaped most of it.

## Impeccable

The interface references: the UI floor, visual direction, model reflexes, motion, native UI, Tailwind, mockups, the UI review in `improve`, and the design-system documentation section.

**Author:** Paul Bakaus

## Platform Design Skills

The Apple Human Interface Guidelines and Material Design 3 rules in the native UI reference, through Impeccable.

**Original work:** https://github.com/ehmo/platform-design-skills
**Author:** ehmo

## Emil Kowalski's Skills

The motion guidance (frequency gate, curves, durations, component motion, springs, gestures, and reduced motion), from `animate`, `animation-performance`, `review-animations`, `apple-design`, `mobile-native`, and `break-ui`.

**Original work:** https://github.com/emilkowalski/skills
**Author:** Emil Kowalski

## Ring

The engineering workflow behind `research`, `develop`, and `review`: test-driven development, systematic debugging, and multi-axis code review.

**Original work:** https://github.com/LerianStudio/ring
**Author:** Lerian Studio

## Matt Pocock's Skills

`grill-me`, `improve-codebase-architecture`, `codebase-design`, `prototype`, `to-spec`, `writing-for-agents`, `tdd`, `diagnosing-bugs`, and `retro`, behind `interview`, `improve`, `prototype`, `spec`, `retro`, `write`, and the testing and debugging references.

**Original work:** https://github.com/mattpocock/skills
**Author:** Matt Pocock

Two rules in `develop`: every changed line traces to the request, and input is trusted past its validated boundary.
